# Student Expense Tracker

A simple Python mini project to track and manage student expenses.

## Features

- Add expenses
- View all expenses
- Calculate total expenses
- Simple menu-based interface

## Technologies Used

- Python

## How to Run

Run the following command:

python expense_tracker.py

## Example

1. Add Expense
2. View Expenses
3. Total Expense
4. Exit
